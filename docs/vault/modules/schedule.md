# Модуль 2 — Расписание (schedule)

Тег: `#tandemika/schedule` · Статус: ⚪ не начат (после [[modules/core|Каркаса]])

## Scope
Бронирование слотов, защита от двойных записей, таймзоны, напоминания.

## Глубина (не голый CRUD)
- Защита от двойных записей: `SELECT ... FOR UPDATE SKIP LOCKED`.
- Хранение времени в UTC, корректная работа с таймзонами на границах.
- Напоминания: воркеры + очередь (Redis-based), идемпотентная доставка.
