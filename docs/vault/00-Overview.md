# Tandemika — Overview

Backend образовательной платформы для репетиторов и учеников.

## Текущий этап
**Модуль 1 — Каркас** (пользователи, роли препод/ученик, связь препод↔ученик, JWT-auth).
Статус: 🟡 в работе — фундамент зафиксирован ([[02-Decisions|ADR-001…004]]), дальше каркас Go-проекта.

## Стек
Go · PostgreSQL · Redis · MinIO/S3 · WebSocket · очередь (Redis-based на старте) ·
Docker Compose · миграции · JWT-auth · OpenAPI/Swagger · GitHub Actions.

## Модули (строятся ПО ОЧЕРЕДИ)
1. [[modules/core|Каркас]] — пользователи, роли, связь препод↔ученик, JWT-auth
2. [[modules/schedule|Расписание]] — бронирование слотов (SELECT FOR UPDATE SKIP LOCKED), таймзоны (UTC), напоминания
3. [[modules/materials|Материалы/файлы]] — стриминговая загрузка, S3/MinIO, presigned URLs, фоновая обработка
4. [[modules/tests|Тесты]] — серверные таймеры, идемпотентная отправка, автопроверка + очередь ручной проверки
5. [[modules/chat|Чат]] — WebSocket, presence, история, офлайн-доставка, Redis Pub/Sub (последним)

## Принципы
- Один модуль за раз; новый — только когда текущий доведён (код + тесты + миграции + доки).
- Глубина важнее ширины: в каждом модуле нетривиальная backend-логика, не голый CRUD.
- Анти-scope: pet-проект для резюме, не стартап.
- Никаких видео/WebRTC (сознательно вне scope).
- Продакшн-привычки: миграция на каждое изменение схемы, тесты на нетривиальную логику.

## Командная работа (нас двое)
- `main` защищён → всё через feature-ветки и PR.
- Логи append-only ([[03-Log]]), задачи живут в [[modules/core|заметках модулей]], ADR только дописываются ([[02-Decisions]]).
